# Write a job description

Include:

1. role summary;
2. outcomes and responsibilities;
3. required qualifications;
4. optional qualifications;
5. team and reporting line; and
6. hiring-process details provided by the requester.

Separate true requirements from preferences. Avoid inflated language and unsupported claims about compensation, benefits, location, or employment terms.
