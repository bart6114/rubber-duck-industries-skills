# Review a UI change

Check:

- expected behavior and acceptance criteria;
- loading, empty, error, success, and disabled states;
- keyboard use, focus, labels, contrast, and screen-reader semantics;
- small and large viewport behavior;
- performance and avoidable layout movement; and
- useful automated and manual tests.

Prioritize issues that affect users. Distinguish defects from optional design preferences.
