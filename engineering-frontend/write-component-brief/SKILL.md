# Write a component brief

Define:

1. purpose and non-goals;
2. content and public properties;
3. variants and visual states;
4. user interactions and emitted events;
5. responsive behavior;
6. accessibility expectations; and
7. examples and edge cases.

Prefer the smallest reusable interface that satisfies known use cases. Mark unresolved design choices as questions.
